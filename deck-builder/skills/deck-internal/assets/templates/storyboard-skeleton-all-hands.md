# Skeleton STORYBOARD — Modo `all-hands`

Aplica Sinek Golden Circle (Why → How → What) + Raskin Strategic Narrative + Kotter visibilizado (se A1 = mudanca organizacional).

`max_ctas: 2` (override SHARED.md — all-hands pode ter ask de prioridades + ask de Q&A engagement).

Arco emocional canonico: Energia alta → Sobriedade factual → Calor humano → Relevancia estrategica → Conexao pessoal → Abertura → Clareza.
Proporcao 30% factual / 70% engajamento + reconhecimento + significado.
