# Deck: Aula Er:YAG Pos-Grad Beauty Smile / Fotona

## Meta
- Skill geradora: deck-teaching
- Objetivo único: Dentistas aplicarem corretamente protocolo Er:YAG em endodontia até final da aula
- Audiência: 18 dentistas pós-graduação, mix iniciantes Er:YAG (12) + experientes (6)
- Duração: 240 min
- Formato: pitch presencial
- Big Idea: Er:YAG não é laser de corte — é instrumento de precisão biológica
- Marca: Fotona (LightWalker — auto-detect)
- Framework principal: Andragogy Knowles + Bloom + Mayer + chunks ≤7min
- Modo: aula-tecnica
- max_ctas: 4
- Gerado em: 2026-05-17T18:30:00-03:00
- Versão: v1

## Estrutura Narrativa

Aula de 4h estruturada em 6 blocos com chunks ≤7min (Mayer). Andragogy explícita: cada módulo abre com "problema real do consultório" antes da teoria. Hands-on 2x (cálculo fluence + protocolo simulado) para Bloom-aplicar. Avaliação final quiz curto para Bloom-aplicar consolidado.

Big Idea ("instrumento de precisão biológica") aparece no slide 2 e se repete como anchor no início de cada módulo. CTA quádrupla (max_ctas=4): protocolo escrito / vídeo de procedimento / grupo de discussão / agendar follow-up clínico.
