# Icons & Emojis Reference

Sistema de icones e emojis do Beauty Smile Design System.

## Lucide React

Biblioteca padrao de icones: **Lucide React**

### Instalacao
```bash
npm install lucide-react
```

### Importacao
```tsx
import { Home, User, Settings, Moon, Sparkles, Zap } from 'lucide-react'
```

### Tamanhos
```tsx
<Icon size={16} />  // Small
<Icon size={20} />  // Default
<Icon size={24} />  // Medium
<Icon size={32} />  // Large
<Icon size={48} />  // XLarge
```

### Stroke Width
```tsx
<Icon strokeWidth={1} />    // Thin
<Icon strokeWidth={1.5} />  // Default
<Icon strokeWidth={2} />    // Bold
```

## Guidelines

### Fazer
- Usar tamanho 20-24px para UI padrao
- Manter strokeWidth consistente (1.5)
- Usar cores semanticas para status
- Adicionar gap de 8px entre icone e texto
- Importar icones individualmente

### Nao Fazer
- Misturar bibliotecas de icones
- Usar tamanhos inconsistentes
- Importar toda a biblioteca
- Usar icones sem significado claro
- Esquecer acessibilidade (aria-label)

## Acessibilidade

```tsx
// Icones decorativos
<Home size={24} aria-hidden="true" />

// Icones com significado
<button aria-label="Fechar modal">
  <X size={24} />
</button>

// Com sr-only
<button>
  <X size={24} aria-hidden="true" />
  <span className="sr-only">Fechar modal</span>
</button>

// Emojis acessiveis
<span role="img" aria-label="Beauty Sleep - Tratamento de Ronco">
  crescent_moon
</span>
```
