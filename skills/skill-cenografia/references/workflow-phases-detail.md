# Detalhamento das 4 Fases do Workflow

Templates de output completos para cada fase do projeto cenografico.

---

## FASE 1: Analise do Briefing (ARCHI + DECOR)

Ao receber material do cliente (briefing, foto, planta, referencia):

### Template de Analise

```
ANALISE DO BRIEFING
━━━━━━━━━━━━━━━━━━━━━━

EVENTO
> Tipo: [stand / camarote / activation / congresso / wellness / social]
> Nome: [nome do evento, se definido]
> Data: [periodo]
> Edicao: [primeira vez / recorrente / N-esima edicao]

MARCA
> Principal: [Fotona / Beauty Smile / Carnaval 360 / outra]
> Secundaria(s): [se houver]
> Hierarquia: [marca unica / primaria+secundaria / co-branding equilibrado]

OBJETIVO
> Objetivo do espaco: [lancamento / experiencia / networking / tratamentos / vendas / educativo]
> Conteudo a gerar: [reels / stories / foto pro / livestream / press]
> KPI principal: [leads / fotos geradas / tratamentos realizados / participantes]

PUBLICO
> Perfil: [influenciadores / medicos / comunidade / classe A-B / misto]
> Quantidade: [pessoas no total]
> Simultaneamente: [pessoas ao mesmo tempo no espaco]
> Tempo de permanencia: [estimativa por pessoa]

ESPACO
> Dimensoes: [estimativa ou fornecida: LxP metros]
> Pe-direito: [metros]
> Local: [indoor / outdoor / misto]
> Cidade/clima: [destino, temperatura esperada]
> Restricoes: [acessos de carga, limitacoes estruturais, horarios]

ORCAMENTO
> Faixa: [$ / $$ / $$$ / $$$$]
> Inclui: [montagem / desmontagem / logistica / F&B]

PRAZO
> Montagem: [dias disponiveis]
> Evento: [duracao]
> Desmontagem: [prazo]
```

### Perguntas Estrategicas (se nao respondidas)

1. Qual o PRINCIPAL momento que o visitante deve ter? (foto, tratamento, networking, aprendizado)
2. Qual conteudo deve ser gerado? (reels, stories, foto profissional, livestream)
3. Ha planta baixa ou dimensoes exatas?
4. Quantas pessoas simultaneamente no espaco?
5. Existe cenografia de edicoes anteriores para referenciar ou evitar?

## FASE 4: Visualizacao (VISION)

### Opcoes ao Usuario

Apos proposta conceitual, SEMPRE oferecer estas opcoes:

```
VISUALIZACAO
━━━━━━━━━━━━

Posso gerar visualizacoes do espaco proposto. Escolha:

A) PROMPT PARA AI STUDIO
   Texto otimizado em ingles para copiar no Google AI Studio / Gemini App.
   Ideal para: geracao rapida, iteracao no navegador.

B) JSON COMPLETO PARA API
   JSON pronto para POST na API do Gemini, com placeholders para imagens de referencia.
   Ideal para: automacao, integracao com scripts, controle total.
   Qual aspect ratio? (16:9 panoramico | 1:1 Instagram | 4:3 apresentacao | 9:16 stories)

C) MULTI-VISTA (3-6 renders)
   Prompts para multiplas perspectivas do mesmo espaco:
   1. Vista geral (wide 24mm, 16:9)
   2. Detalhe backdrop (medium 35mm, 1:1)
   3. Vista lounge (eye-level 35mm, 16:9)
   4. Vista aerea/isometrica (bird's eye, 4:3)
   5. Vinheta decoracao (close-up 85mm, 1:1)
   6. Backdrop para stories (vertical 9:16)
   Quer todas ou alguma especifica?
```

### Processo de Geracao

1. Traduzir TODAS as especificacoes das Fases 2 e 3 para ingles
2. Selecionar template adequado de `nano-banana-templates.md`
3. Preencher categorias cinematograficas com detalhes do projeto
4. Incluir instrucoes de imagens de referencia se fornecidas pelo usuario
5. Gerar JSON completo se solicitado (Template A, B ou C)
6. Revisar prompt para maxima especificidade antes de entregar

### Aspect Ratio por Uso

| Uso | Ratio | Quando |
|-----|-------|--------|
| Vista geral panoramica | 16:9 | Apresentacoes, decks, visao completa |
| Instagram feed | 1:1 ou 4:5 | Posts, detalhes, vinhetas |
| Instagram stories/reels | 9:16 | Conteudo vertical, backdrop |
| Apresentacao corporativa | 4:3 ou 16:9 | Slides, propostas |
| Banner/header | 21:9 | Site, capa de proposta |
| Before/After | 16:9 | Comparativos lado a lado |
| Planta 3D | 4:3 | Visao aerea do layout |

### Instrucoes para Imagens de Referencia

Quando o usuario fornecer imagens:

1. **Imagem do espaco vazio:** Usar como base para transformacao (Template B)
2. **Imagens de mobiliario/objetos:** Incluir como inline_data, referenciar por nome no prompt
3. **Logo/brand assets:** Incluir como inline_data, instruir posicionamento
4. **Mood board:** Usar como inspiracao de estilo, nao como base literal
5. **Fotos de eventos anteriores:** Referenciar para manter ou evitar elementos

Para converter imagens para base64, ver instrucoes em `nano-banana-templates.md`.
