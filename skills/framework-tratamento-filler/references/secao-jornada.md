# Seção 3: Jornada do Cliente

Guia detalhado para preenchimento da terceira seção do Framework de Tratamento usando a persona **UX/CX Designer**.

---

## 🎯 Objetivo da Seção

Mapear a **experiência completa** do cliente do primeiro contato ao pós-tratamento:
- Como descobre que tem o problema
- O que avalia antes de decidir
- O que faz decidir AGORA
- O que espera durante a experiência
- Que mensagens funcionam em cada momento

**Saída esperada:** Jornada clara que informa estratégia de conteúdo, vendas e experiência.

---

### 5. Messaging Framework

**Estrutura por estágio:**
```
### [Estágio]
- **Mensagem principal:** [O que comunicar]
- **Call-to-Action:** [Ação desejada]
- **Canais:** [Onde comunicar]
```

**Progressão do messaging:**
- Awareness: Reconhecer problema → Despertar curiosidade
- Consideration: Mostrar solução → Gerar desejo
- Decision: Remover objeções → Criar urgência
- Experience: Validar escolha → Gerar indicação

---

## 🧠 Persona em Ação

### Pensamento Durante Análise

1. **Mapear touchpoints:**
   - "Onde ele entra em contato com a marca primeiro?"
   - "Quais são os momentos da verdade?"

2. **Identificar fricções:**
   - "O que dificulta a passagem de um estágio para outro?"
   - "Onde perdemos pessoas na jornada?"

3. **Conectar emoção com momento:**
   - "Como ele se sente em cada fase?"
   - "A mensagem reconhece esse sentimento?"

### Tom de Entrega

```
Mapeei a jornada completa do cliente analisando [materiais].

O cliente típico leva [tempo] do primeiro contato até a decisão.

Os momentos críticos são:
1. [Momento] - onde [insight]
2. [Momento] - onde [insight]

A maior fricção está em [fase], causada por [razão].
```

## ✅ Checklist de Qualidade

Antes de entregar Seção 3:

- [ ] Gatilhos de descoberta são específicos
- [ ] Canais batem com perfil do ICP
- [ ] Critérios incluem emocionais, não só funcionais
- [ ] Tempo na fase Consideration é realista para o ticket
- [ ] Gatilhos de urgência são acionáveis
- [ ] Barreiras são as mesmas do 3D
- [ ] Messaging evolui de awareness → action
- [ ] CTAs são claros por fase
- [ ] 3 itens por subseção
