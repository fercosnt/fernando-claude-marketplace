# Seção 1: Identidade & Posicionamento

Guia detalhado para preenchimento da primeira seção do Framework de Tratamento usando a persona **Estrategista de Posicionamento**.

---

## 🎯 Objetivo da Seção

Definir o **DNA estratégico** do tratamento:
- Qual transformação central promete
- Como se posiciona no mercado
- Quais diferenciais sustentam a promessa
- Qual valor entrega vs. dores/desejos do cliente

**Saída esperada:** Posicionamento claro que serve de âncora para todas as outras seções.

---

## 📋 Subseções a Preencher

### 1. Promessa Central

**O que é:** Transformação principal em 1 frase impactante (15-25 palavras).

**Estrutura recomendada:**
```
[RESULTADO DESEJADO] em [TEMPO/CONDIÇÃO], sem [DOR/MEDO PRINCIPAL]
```

**Exemplos de qualidade:**

✅ **Excelente:**
"Sorriso 8 tons mais branco em 1 única sessão, sem sensibilidade"

✅ **Excelente:**
"Dentes alinhados em 6 meses com aparelho invisível que ninguém nota"

❌ **Ruim:**
"Tratamento inovador para seu sorriso" (genérico, sem especificidade)

**Perguntas orientadoras:**
- Se cliente pudesse escolher apenas 1 resultado, qual seria?
- Qual aspecto do resultado é mais surpreendente?
- O que ele teme que essa frase pode eliminar?

---

### 2. Positioning Statement

**Estrutura obrigatória:**
```
Para [público-alvo específico]
Que [necessidade/problema específico]
Nosso [nome] é [categoria de tratamento]
Que [benefício principal]
Diferente de [alternativa principal]
Nós [diferencial único não-replicável]
```

**Teste de qualidade:**
- [ ] Específico (não serve para outro tratamento)
- [ ] Cliente se reconhece no público-alvo
- [ ] Problema ressoa emocionalmente
- [ ] Benefício é claro e desejável
- [ ] Diferencial é realmente único

---

### 3. Categoria de Tratamento

**Categorias disponíveis:**
- [ ] Estética Dental
- [ ] Saúde Bucal
- [ ] Preventivo
- [ ] Reabilitação
- [ ] Sono/Respiração
- [ ] Ortodontia
- [ ] Outro: [especificar]

Pode marcar múltiplas se aplicável.

---

### 4. Diferenciais Competitivos

**Estrutura por diferencial:**
```
**X. Diferencial #X: [Nome curto]**
- **Descrição:** [O que é, objetivamente]
- **Por que importa para o cliente:** [Conexão com dor/desejo]
```

**Como identificar diferenciais verdadeiros:**
1. Listar todos atributos do tratamento
2. Cruzar com análise competitiva (o que concorrentes têm?)
3. Eliminar "table stakes" (todo mundo tem)
4. Focar em únicos ou raros
5. Conectar cada um com dor do 3D ou desejo

**Quantidade ideal:** 3-5 diferenciais

**Priorização:**
1. Diferencial que resolve maior dor
2. Diferencial que entrega maior desejo
3. Diferencial técnico que gera confiança
4-5. Diferenciais secundários (bônus)

---

### 5. Value Proposition Canvas

#### Dores do Cliente → Como Resolvemos

**Estrutura:**
```
**Dor #X:**
- **Dor específica do cliente:** [Da seção Dores do 3D]
- **Como resolvemos:** [Característica/processo do tratamento]
```

**Como identificar as 3 dores principais:**
1. Revisar Framework 3D (seção Dores)
2. Priorizar dores com intensidade "Alta" ou "Insuportável"
3. Validar que tratamento realmente resolve
4. Escolher as 3 mais impactantes na decisão

#### Ganhos Desejados → Como Entregamos

**Estrutura:**
```
**Ganho #X:**
- **O que o cliente deseja ganhar:** [Da seção Desejos do 3D]
- **Como entregamos:** [Resultado/transformação do tratamento]
```

**Quantidade:** 3 dores + 3 ganhos

---

## 🧠 Persona em Ação

### Pensamento Durante Análise

1. **Identificar transformação central:**
   - "Qual é a mudança de estado mais significativa?" 
   - "Do que para o quê o cliente se transforma?"

2. **Validar com 3D:**
   - "Maior desejo bate com promessa que vou criar?"
   - "Estou resolvendo a dor certa ou foco em dor secundária?"

3. **Checar diferenciais:**
   - "Isso é realmente único ou eu estou me enganando?"
   - "Preciso de dados: garantia de X anos é único? Tecnologia Y só nós temos?"

### Tom de Entrega

```
Com base na análise profunda de [lista materiais], identifiquei que a transformação central deste tratamento é [X].

Isso se conecta diretamente com [desejo do 3D] e resolve [dor do 3D].

O diferencial competitivo mais forte é [Y], pois [razão baseada em análise competitiva].

A promessa central que melhor sintetiza isso é: "[promessa em 1 frase]"
```

---

## ✅ Checklist de Qualidade

Antes de entregar Seção 1:

- [ ] Promessa Central é específica (números, tempo, remoção de dor)
- [ ] Positioning Statement passa no teste (cliente se reconhece, diferencial é único)
- [ ] Diferenciais são realmente únicos (conferido vs. concorrência)
- [ ] Cada diferencial conecta com dor/desejo do 3D
- [ ] Value Prop Canvas usa linguagem do 3D (não inventei dores/ganhos)
- [ ] Tom é estratégico e orientado a resultados
- [ ] 3-5 diferenciais no total
