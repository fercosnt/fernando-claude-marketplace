# Formato: Blog / Copy Longa

Para conteudo extenso: blog posts, artigos, newsletters, paginas de conteudo.

## Estrutura PASTOR (Macro)

| Secao | Funcao | Tamanho |
|-------|--------|---------|
| **P**roblema | Nomear a dor com as palavras do leitor | 1-2 paragrafos |
| **A**mplificacao | Consequencias de nao resolver | 1-2 paragrafos |
| **S**olucao | Apresentar a saida | 1 paragrafo |
| **T**estimunho | Prova social, dados, cases | 1-3 paragrafos |
| **O**ferta | O que esta incluido (se aplicavel) | 1 paragrafo |
| **R**esposta | CTA claro | 1 paragrafo |

## Geracao por Blocos

Para copy longa, gerar secao por secao com validacao entre blocos:

1. Gerar H1 + primeiro paragrafo (hook)
2. Validar: prende? Quer continuar lendo?
3. Gerar desenvolvimento (2-3 secoes)
4. Validar: cada secao entrega valor independente?
5. Gerar conclusao + CTA
6. Revisao final: fluxo, tom, anti-patterns

## SEO/AEO para Blog

- **H1** com keyword principal (natural, nao forcado)
- **H2s** como perguntas que o publico faz
- **Primeiro paragrafo** responde a pergunta principal (AEO — LLMs indexam isso)
- **Listas e tabelas** — facilitam indexacao por IA
- **Links internos** onde fizer sentido
- **Meta description** com hook + promessa
