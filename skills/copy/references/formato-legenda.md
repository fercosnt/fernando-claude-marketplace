# Formato: Legenda de Post (Estatico ou Carrossel)

A legenda e o texto que acompanha o visual. Em estaticos, e a copy principal. Em carrosseis, complementa.

## Estrutura Base

```
Hook (90-125 caracteres — antes do "ver mais")
↓
2-3 frases de desenvolvimento (valor, contexto, historia)
↓
Pergunta de engajamento
↓
CTA explicito + hashtags (3-5 especificas)
```

## 5 Formulas de Legenda

### 1. Educativa
**Estrutura:** Hook + dica numerada/breakdown + CTA pergunta
**Quando:** Posts de valor, dicas, hacks
**Exemplo:**
```
O hook perfeito tem 4 ingredientes.

1. Util — resolve um problema real
2. Urgente — por que agora
3. Unico — diferente do que ja viram
4. Ultra-especifico — numeros e detalhes

Se menos de 3 ativos, reescreva.

Qual desses voce mais esquece? Comenta 👇
```

### 2. Narrativa (Mini Blog)
**Estrutura:** Anedota pessoal → licao extraida → reflexao → pergunta
**Quando:** Storytelling, conexao emocional, behind-the-scenes
**Exemplo:**
```
Postei 30 dias seguidos e meu alcance CAIU.

No dia 31 parei tudo. Fui olhar os numeros.
Os posts que performaram tinham UMA coisa em comum:
nenhum seguia o calendario editorial.

Eram os que eu escrevi por impulso.
Os que vinham de experiencia real, nao de template.

O algoritmo nao premia frequencia.
Premia autenticidade.

Voce ja passou por isso? Me conta 👇
```

### 3. Humor/Atrevimento
**Estrutura:** Contraste/comparacao engracada → tensao reconhecivel → CTA identificacao
**Quando:** Entretenimento, relatability, engajamento leve
**Exemplo:**
```
Eu fazendo copy: pesquiso, estruturo, reviso 3 vezes.
O post que bombou: uma foto torta do almoco com "segunda-feira 🫠"

O algoritmo nao le SKILL.md aparentemente.

Marca alguem que ja viveu isso 😂
```

### 4. Behind-the-Scenes
**Estrutura:** Admissao real → reframe de perspectiva → pergunta vulneravel
**Quando:** Autenticidade, bastidores, humanizacao
**Exemplo:**
```
Quase nao postei hoje.

To com 3 projetos atrasados, inbox lotado e aquela voz dizendo "ninguem vai notar se voce sumir um dia".

Mas a verdade e que consistencia nao e postar todo dia.
E nao desistir quando a vontade bate.

Esse post e pra voce que tambem ta nessa hoje.
Comenta um ☀️ se ta resistindo.
```

### 5. Fill-in-the-Blank
**Estrutura:** Template para completar + pedido de tag
**Quando:** Volume de comentarios, engajamento rapido, baixo esforco
**Exemplo:**
```
Completa a frase:

"Se eu pudesse voltar no tempo, diria pro meu eu de 1 ano atras: ___________"

Comeca nos comentarios 👇
Depois marca alguem que precisa ouvir isso.
```

## Boas Praticas

- **Hook nos primeiros 90-125 caracteres** — e o que aparece antes do "ver mais" no mobile
- **Espacamento entre blocos** — quebra de paragrafos com linhas em branco aumenta legibilidade
- **Emojis como separadores visuais** — nao como decoracao. 1-3 por legenda no maximo
- **Tom alinhado com brand voice** — se voice profile configurado, seguir
- **Um CTA por legenda** — nao "segue + comenta + salva + manda"
- **Evitar hashtags genericas** — #marketing #empreendedorismo nao geram alcance qualificado
- **Hashtags especificas de nicho** — 3-5 que o publico-alvo realmente busca

## Tamanho por Contexto

| Tipo de post | Tamanho ideal | Observacao |
|-------------|---------------|-----------|
| Estatico simples | 40-100 palavras | Brevidade performa |
| Carrossel educativo | 50-150 palavras | Complementar, nao repetir |
| Post de storytelling | 100-300 palavras | Formato narrativa |
| Carrossel de case | 30-80 palavras | Slides contam a historia |

## Template de Output

```
## LEGENDA — [Tema]

**Formula:** [Educativa / Narrativa / Humor / BTS / Fill-in-the-Blank]
**Tamanho:** [X palavras]

---

[A legenda completa, ja formatada com espacamentos]

---

### Hashtags
#hashtag1 #hashtag2 #hashtag3

### Notas
- [tom, emoji strategy, timing]
```
