# Formato: Post Estatico

O post estatico e julgado pelo visual primeiro e pela legenda depois. O copy na imagem funciona como headline de anuncio.

## Elementos

| Elemento | Regra | Detalhe |
|----------|-------|---------|
| **Visual headline** | Hook em ate 7 palavras | Mais curto e impactante possivel |
| **Legenda** | 40-100 palavras | Brevidade performa melhor que legendas longas |
| **CTA** | Pergunta ou "Salva" | Evitar links (algoritmo penaliza) |

## Estrutura

```
IMAGEM:
  Headline visual (ate 7 palavras)
  Sub-headline opcional (1 frase curta)

LEGENDA:
  Hook (reforcar ou expandir headline visual)
  1-2 frases de valor
  CTA unico
  Hashtags (3-5)
```

## Frameworks para Post Estatico

| Objetivo | Framework | Headline visual |
|----------|-----------|-----------------|
| Dica rapida | SCQA resumido | "[Numero] [coisa] que [resultado]" |
| Opiniao forte | TAS resumido | "Nao e [crenca popular]. E [verdade]." |
| Empatia | PAS resumido | "[Dor em 5 palavras]" |
| Motivacao | BAB resumido | "[Antes] → [Depois]" |

## Template de Output

```
## POST ESTATICO — [Tema]

---

### Texto na Imagem
**Headline:** [ate 7 palavras]
**Sub-headline:** [opcional, 1 frase]

### Legenda
[40-100 palavras]

### Hashtags
#hashtag1 #hashtag2 #hashtag3

### Notas de Producao
- [cores, tipografia, estilo visual]
```
