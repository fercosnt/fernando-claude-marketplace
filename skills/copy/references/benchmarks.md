# Benchmarks de Plataformas para Social Media Copy

Referencia rapida de metricas, horarios e formatos por plataforma.

---

## Engagement Rate por Plataforma

| Plataforma | ER medio | ER excelente | Formato dominante |
|-----------|----------|-------------|-------------------|
| Instagram Feed | 1.22% | >6% | Carrosseis |
| Instagram Reels | 0.50% | >3% | Video curto |
| TikTok | 5.96% | >15% | Video curto |
| LinkedIn | 2.0% | >5% | Posts longos + carrosseis |
| Facebook | 0.07% | >1% | Video |
| Twitter/X | 0.05% | >0.5% | Thread |

**Nota:** ER = (interacoes / alcance) x 100. Valores sao medianas globais e variam por nicho e tamanho de conta.

---

## Valor Monetario de Engajamento

Referencia para calcular ROI de conteudo organico:

| Acao | Valor estimado |
|------|---------------|
| Like | R$ 0,50 |
| Comentario | R$ 2,00 |
| Compartilhamento | R$ 5,00 |
| Salvamento | R$ 3,00 |

**Hierarquia de valor:** Compartilhamento > Salvamento > Comentario > Like

- Salvamento = conteudo de referencia (o usuario quer voltar)
- Compartilhamento = prova social (o usuario se identifica publicamente)
- Comentario = conexao (o usuario investiu tempo para responder)
- Like = reconhecimento minimo (baixo esforco)

## Tamanho Ideal de Conteudo

| Plataforma | Formato | Tamanho ideal |
|-----------|---------|---------------|
| Instagram Feed | Legenda | 150-300 caracteres (ou 2000+ para storytelling) |
| Instagram Feed | Carrossel | 7-10 slides, 30-50 palavras por slide |
| Instagram Reels | Video | 15-30s (hook nos primeiros 3s) |
| TikTok | Video | 21-34s (hook no primeiro segundo) |
| LinkedIn | Post texto | 1200-1600 caracteres (usar quebras de linha) |
| LinkedIn | Carrossel PDF | 8-12 slides, texto conciso |
| Facebook | Post | 40-80 caracteres (posts curtos performam melhor) |
| Facebook | Video | 1-3 min |
| Twitter/X | Tweet unico | 71-100 caracteres |
| Twitter/X | Thread | 5-10 tweets, cada um auto-contido |
| Blog | Artigo | 1500-2500 palavras (SEO otimizado) |

## Hashtags por Plataforma

| Plataforma | Qtd recomendada | Estrategia |
|-----------|----------------|-----------|
| Instagram | 5-10 | Mix: 3 nicho + 3 medio alcance + 2 amplas. Evitar hashtags banidas. Colocar na legenda (nao nos comentarios). |
| TikTok | 3-5 | Priorizar trending + nicho. Hashtags funcionam como keywords de busca. |
| LinkedIn | 3-5 | Usar hashtags de industria/cargo. Evitar genricas tipo #sucesso. |
| Facebook | 0-2 | Hashtags tem impacto minimo. Usar apenas para campanhas especificas. |
| Twitter/X | 1-2 | Maximo 2. Mais que isso reduz engajamento. Priorizar trending topics. |

**Regra de ouro:** Hashtag boa = seu publico-alvo pesquisa por ela. Se ninguem busca, nao serve.

---

## Resumo Operacional

- **Instagram:** Carrosseis para educar, Reels para alcance, Stories para conexao diaria
- **TikTok:** Volume + velocidade. Hook instantaneo. Trends sao combustivel.
- **LinkedIn:** Autoridade + storytelling profissional. Posts longos com espacamento generoso.
- **Facebook:** Comunidades e video. Alcance organico limitado — priorizar grupos.
- **Twitter/X:** Opiniao + curadoria. Threads para conteudo denso. Frequencia alta.
