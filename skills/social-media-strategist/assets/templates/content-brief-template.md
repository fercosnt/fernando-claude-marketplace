## Direção Visual

> O briefing visual segue o princípio "Show, Don't Tell" — não use 10 segundos de fala para explicar algo que uma imagem pode mostrar.

**Cadeia do Ser (K-Visual):** Todos os elementos visuais devem pertencer ao mesmo campo de valor do arquétipo da marca.

| Elemento | Orientação |
|----------|-----------|
| **Cenário** | [Onde? Escritório, estúdio, rua, casa — deve comunicar o arquétipo] |
| **Iluminação** | [Natural / Estúdio / Ring light / Ao ar livre] |
| **Indumentária** | [O que vestir — alinhado à cadeia do ser da marca] |
| **Inserts visuais** | [Imagens, B-roll, capturas de tela — o que mostrar enquanto fala] |
| **Texto na tela** | [Headlines, bullet points, destaques — para reforçar sem áudio] |
| **Paleta** | [Cores dominantes alinhadas à identidade visual] |

**IMPORTANTE:** Não usar bancos de imagens genéricos (stock photos). Inserts devem ser do universo real da marca.

## Specs Técnicas

### Reel
- Formato: 9:16 | 1440x2560px ideal
- Duração: [especificar — 15-90s, sweet spot 60-90s]
- Safe zone: 310px livres no topo e base
- Legenda: primeiras 2 linhas visíveis sem expandir

### Carrossel
- Formato: 4:5 (1080x1350px) ou 1:1 (1080x1080px)
- Slides: [quantidade — mínimo 3, ótimo 7-10]
- Texto por slide: máximo 3-4 linhas
- Vídeos em carrossel NÃO aparecem no feed de Reels

### Story
- Formato: 9:16 | 1080x1920px
- Máximo: 5 stories por sessão
- Interatividade: [poll / quiz / pergunta / link / countdown]
- Posicionar elementos na zona segura

### Estático
- Formato: 4:5 (1080x1350px) — grid atualizado para 4:5 desde jan/2025
- NÃO usar 1:1 (será cortado no grid)

## Checklist de Aprovação

### Pré-produção
- [ ] Triângulo de Conteúdo preenchido (Ideia, Objetivo, Interação, Mensagem)
- [ ] Pilar e posição no funil definidos
- [ ] Gancho dos 3 primeiros segundos funciona SEM SOM
- [ ] Estrutura segue Método Avião (Senso Comum → Desenvolvimento → Técnica)
- [ ] Direção visual alinhada à Cadeia do Ser da marca

### Pós-produção (antes de publicar)
- [ ] Specs técnicas corretas para o formato
- [ ] Legenda com keywords e CTA
- [ ] Efeito Escorregador: a leitura/visualização desliza sem atrito
- [ ] Gera pelo menos 1 desequilíbrio na audiência (cognitivo, identitário ou comportamental)
- [ ] Não viola as regras do nicho (compliance, se aplicável)
