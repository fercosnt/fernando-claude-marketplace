# Métricas de Referência e Benchmarks — Instagram 2025-2026

## 1. Fórmulas de Cálculo

### Engagement Rate (ER)
```
ER = (Curtidas + Comentários + Salvamentos + Compartilhamentos) ÷ Total de Visualizações × 100
```

### Hook Rate
```
Hook Rate = Visualizações que ultrapassam 3 segundos ÷ Total de Visualizações × 100
```

### Taxa de Interação (Reels)
```
Taxa de Interação = (Curtidas + Comentários + Salvamentos + Compartilhamentos) ÷ Total de Views × 100
```

### Save Rate
```
Save Rate = Salvamentos ÷ Impressões × 100
```

## 3. Regras Algorítmicas Quantificadas

### Regra 50/10 para Reels

Para que um Reel receba distribuição orgânica contínua, precisa bater **simultaneamente**:

| Métrica | Threshold | Consequência se falhar |
|---------|-----------|----------------------|
| **Hook Rate** | >50% | Entrega orgânica congelada |
| **Taxa de Interação** | >10% das views | Entrega orgânica congelada |

Reels com Hook Rate de 46% ou interação abaixo de 10% têm sua distribuição interrompida pelo algoritmo.

### Composição do Feed (Home)

| Tipo de conteúdo | % do feed | Implicação |
|-----------------|-----------|------------|
| Reels | 60% | 3x mais chance de aparecer organicamente |
| Anúncios patrocinados | 20% | Espaço fixo do algoritmo |
| Posts estáticos/Carrosséis | 20% | Competem entre si por 1/5 do feed |

### O que o algoritmo ignora ou penaliza

- Likes isolados sem outros sinais
- Seguidores novos sem atividade
- Posts sem engajamento nas primeiras horas
- Conta inativa por semana (fica abaixo do baseline)
- Conteúdo postado de forma irregular

## 8. Como Usar Estes Benchmarks

### No Modo Review (Análise de Performance)

1. Compare ER do post com benchmarks do formato
2. Verifique Hook Rate dos Reels (>50% = OK, <50% = problema no gancho)
3. Analise save rate dos carrosséis (métrica emergente)
4. Cruze shares via DM com alcance (principal sinal algorítmico)

### Na Aprovação de Conteúdo (Pré-publicação)

- Reel só recebe verba de impulsionamento se bater >50% Hook Rate E >10% interação organicamente
- Carrossel deve ter pelo menos 3 slides "ganchos independentes" (Gancho Triplo)
- Story deve incluir pelo menos 1 elemento interativo (poll, quiz, pergunta)

### No Planejamento (Calibração de expectativas)

- ER de 0.36% é o mediano — não é "ruim", é normal
- ER >1% já coloca no top 25% das marcas
- Shares via DM são o novo "like" — otimizar para compartilhamento, não para curtida
